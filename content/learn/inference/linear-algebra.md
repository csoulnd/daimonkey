# 线性代数：向量、矩阵与线性变换

模型里经常出现这样的公式：`Y = XW`。它看起来很短，却同时包含三个问题：输入是什么，权重怎样组合输入，输出形状为什么如此。

本篇从一组小数字开始，把这三个问题拆开。先理解向量与点积，再理解矩阵乘法和线性变换，最后回到模型中的线性层及 Attention。读完之后，你应当能手算一次小矩阵乘法，说明它的几何含义，并检查常见模型公式的维度。

前置只需要基本代数。本文讨论实数、有限维向量和二维矩阵；更高阶的张量、内存布局及数据类型放在后续章节。

## 1. 从两个输入特征到三个输出特征

假设某个 token 当前由两个数表示：`x₁ = 1`、`x₂ = 2`。我们希望通过三条规则得到新的表示：

```text
y₁ =  x₁ + 2x₂ = 5
y₂ =       x₂ = 2
y₃ = 2x₁ −  x₂ = 0
```

每个输出都是输入分量的加权和。把三条规则放在一起，就可以写成矩阵形式：

```text
    ⎡ 1   2 ⎤        ⎡ 1 ⎤        ⎡ 5 ⎤
A = ⎢ 0   1 ⎥    x = ⎣ 2 ⎦    y = ⎢ 2 ⎥
    ⎣ 2  −1 ⎦                      ⎣ 0 ⎦

y = Ax
```

这里 `A` 有 3 行、2 列，记作形状 `3 × 2`；`x` 是 `2 × 1` 的列向量；`y` 是 `3 × 1` 的列向量。矩阵的每一行保存一条输出规则，乘法把规则应用到输入上。

这个例子中的数值由我们手工指定。模型中的权重通常由训练得到，但计算仍然可以按这样的加权和理解。这里的“特征”只是表示中的一个分量，不意味着每个分量都能独立对应某个可命名的语义。

全文约定：小写字母如 `x`、`y` 表示向量，大写字母如 `A`、`X` 表示矩阵；`xᵢ` 表示向量第 `i` 个分量，`Aᵢⱼ` 表示矩阵第 `i` 行、第 `j` 列的元素。数学推导默认用列向量，进入模型计算时再明确改用按行排列的表示。

## 2. 向量：坐标和线性组合

### 2.1 向量为什么能写成一列数

二维几何中的向量可以理解为一个有方向、有长度的位移。例如，从原点向右走 1、向上走 2，对应坐标 `(1, 2)`。

在标准坐标系里，我们选定两个基本方向：

```text
e₁ = [1, 0]ᵀ    e₂ = [0, 1]ᵀ
x  = [1, 2]ᵀ = 1e₁ + 2e₂
```

上标 `ᵀ` 表示转置，这里把横着写的一行数变成列向量。`e₁`、`e₂` 是二维空间的一组标准基；坐标 `(1, 2)` 告诉我们沿两个基方向分别取多少。

向量和它的坐标需要区分：同一个几何向量，换一组基，坐标可以不同。本文固定使用标准基，因此可以直接用一列数表示向量，不再反复标注坐标系。

当向量有 `d` 个实数分量时，写作 `x ∈ ℝᵈ`。`∈` 表示“属于”，`ℝᵈ` 表示所有 `d` 维实数向量组成的空间。高维向量不容易画出来，但逐分量计算的规则不变。

### 2.2 加法、数乘与线性组合

同维向量相加，就是对应分量相加；用一个数乘向量，就是把每个分量都乘这个数。这个数叫作标量。

```text
u = [1, 2]ᵀ    v = [3, −1]ᵀ

u + v   = [4, 1]ᵀ
2u      = [2, 4]ᵀ
2u − v  = [−1, 5]ᵀ
```

`2u − v` 是一个线性组合：先给若干向量乘上标量，再相加。一般形式是 `c₁v₁ + c₂v₂ + … + cₖvₖ`。

为什么要记住“线性组合”？因为矩阵乘向量，正是在按输入分量给矩阵的列加权，再把它们加起来。后面会用同一个例子验证这一点。

## 3. 点积：把两个向量变成一个数

### 3.1 点积怎样计算

两个同维实数向量的点积，是对应分量相乘后求和：

```text
u · v = uᵀv = u₁v₁ + u₂v₂ + … + u_dv_d

[1, 2] · [3, −1] = 1×3 + 2×(−1) = 1
```

结果是一个标量，不是向量。开篇的第一条规则 `y₁ = x₁ + 2x₂`，就是权重向量 `[1, 2]` 与输入向量的点积。

点积和逐元素乘法不同。逐元素乘法会保留每个位置的乘积，例如 `[1, 2]` 与 `[3, −1]` 逐元素相乘得到 `[3, −2]`；点积还要把这些乘积相加，得到 `1`。

### 3.2 长度与方向为什么都会影响点积

向量的欧氏长度也叫二范数，记为 `‖x‖₂`：把每个分量平方、求和，再开平方。例如 `x = [1, 2]ᵀ` 的长度是 `√5`。

对于两个非零向量，有：

```text
u · v = ‖u‖₂ ‖v‖₂ cos θ
```

`θ` 是它们之间的夹角。方向相同，余弦为 1；互相垂直，余弦为 0；方向相反，余弦为 −1。垂直的向量也叫正交向量。

因此，点积既取决于方向，也取决于长度。把 `v` 乘 10，方向不变，但它与 `u` 的点积会乘 10。若只想比较方向，可以对非零向量用点积除以两个长度，得到余弦相似度。

投影则回答另一个问题：`u` 沿某个方向的部分有多少？若 `v` 是单位向量，也就是长度为 1，那么 `u` 在它所指直线上的正交投影是 `(u · v)v`。先用点积求沿这个方向的有符号长度，再乘单位方向向量。例如把 `[1, 2]ᵀ` 投影到横轴上，得到 `[1, 0]ᵀ`。

这些长度、角度和正交关系采用通常的欧氏点积。可进一步参阅教材的[点积与正交](https://textbooks.math.gatech.edu/ila/dot-product.html)一节。

## 4. 矩阵乘法：同一次计算的两种看法

### 4.1 按行看：每个输出都是一次点积

回到开篇的 `A` 与 `x`：

```text
    ⎡ 1   2 ⎤        ⎡ 1 ⎤
A = ⎢ 0   1 ⎥    x = ⎣ 2 ⎦
    ⎣ 2  −1 ⎦

Ax = [1×1 + 2×2, 0×1 + 1×2, 2×1 + (−1)×2]ᵀ
   = [5, 2, 0]ᵀ
```

每一行与输入做一次点积，得到一个输出分量。若 `A` 的形状是 `m × n`，它就有 `m` 条规则，每条规则读取 `n` 个输入分量。

### 4.2 按列看：输出是矩阵列向量的线性组合

把 `A` 的两列分别记为 `a₁` 和 `a₂`：

```text
a₁ = [1, 0, 2]ᵀ    a₂ = [2, 1, −1]ᵀ

Ax = x₁a₁ + x₂a₂
   = 1×[1, 0, 2]ᵀ + 2×[2, 1, −1]ᵀ
   = [5, 2, 0]ᵀ
```

按行看，便于逐个计算输出；按列看，便于理解输出能落在什么空间里。这是同一次运算的两种解释。

### 4.3 从矩阵乘向量到矩阵乘矩阵

假设同时有两个输入向量 `x = [1, 2]ᵀ` 和 `z = [3, −1]ᵀ`。先按列排成矩阵 `C`：

```text
C = [x  z] = ⎡ 1   3 ⎤
             ⎣ 2  −1 ⎦

AC = [Ax  Az] = ⎡ 5   1 ⎤
                ⎢ 2  −1 ⎥
                ⎣ 0   7 ⎦
```

矩阵乘矩阵可以理解为：对右边矩阵的每一列，应用左边矩阵表示的同一套规则。具体计算时，结果第 `i` 行、第 `j` 列的元素，等于左边第 `i` 行与右边第 `j` 列的点积。

形状规则为：

```text
(m × n) @ (n × p) → (m × p)
```

这里 `@` 表示矩阵乘法。中间的 `n` 必须相等，因为点积要求分量数相同；结果保留左边的行数 `m` 和右边的列数 `p`。结果元素可写为 `(AC)ᵢⱼ = Σₖ AᵢₖCₖⱼ`，其中 `k` 从 1 遍历到 `n`，`Σ` 表示求和。

矩阵转置会交换行与列，`(Aᵀ)ⱼᵢ = Aᵢⱼ`。本例 `Aᵀ` 的形状是 `2 × 3`。注意：转置通常不是求逆，它没有“撤销变换”的含义。

## 5. 线性变换：矩阵描述了一套怎样的规则

### 5.1 “线性”有明确条件

把输入 `x` 映射到 `Ax` 的规则记为 `T(x)`。它满足：

```text
T(u + v) = T(u) + T(v)    可加性
T(cu)    = cT(u)         齐次性
```

两条合起来，就是 `T(αu + βv) = αT(u) + βT(v)`。这种保持线性组合的变换叫线性变换。

例如 `T(x) = 2x` 是线性的，`T(x) = x²`（一维情形）不是，因为平方一般不保持加法。线性变换必定把零向量映射到零向量；但“零映射到零”只是必要条件，不能单独证明线性，平方函数就是反例。

### 5.2 矩阵的列记录了基向量的去向

对二维输入，`x = x₁e₁ + x₂e₂`。由线性条件：

```text
T(x) = x₁T(e₁) + x₂T(e₂)
```

所以，只要知道两个基向量分别被送到哪里，就能确定所有输入的输出。本例中：

```text
Ae₁ = [1, 0, 2]ᵀ = A 的第一列
Ae₂ = [2, 1, −1]ᵀ = A 的第二列
```

这也解释了矩阵乘法的列组合规则。在选定输入与输出的基之后，一个有限维线性变换就可以用矩阵表示。教材的[线性变换](https://textbooks.math.gatech.edu/ila/linear-transformations.html)一节给出了相应定义与证明。

下面三个二维例子可以用基向量的去向来理解：

| 矩阵（分号分隔两行） | 基向量的去向 | 对任意 `(a, b)` 的作用 |
|---|---|---|
| `S = [2, 0; 0, 1]` | 横向基变为原来的两倍，纵向基不变 | `(2a, b)`，横向伸缩 |
| `R = [0, −1; 1, 0]` | 向右变向上，向上变向左 | `(−b, a)`，逆时针旋转 90° |
| `P = [1, 0; 0, 0]` | 横向基不变，纵向基变为零 | `(a, 0)`，投影到横轴 |

输入网格经过伸缩后会横向拉宽，经过旋转后整体转向，经过投影后会压到一条线上。矩阵并不只用于几何变换，但这些例子能帮助理解“对整个空间应用同一套规则”。

### 5.3 变换的复合决定乘法顺序

先做 `A`，再做 `B`，列向量的计算是 `B(Ax) = (BA)x`。因此公式里靠近输入的矩阵先起作用。

次序一般不能交换。例如对 `x = [1, 2]ᵀ`：

```text
先 S 后 R：x → [2, 2]ᵀ  → [−2, 2]ᵀ，也就是 RSx
先 R 后 S：x → [−2, 1]ᵀ → [−4, 1]ᵀ，也就是 SRx
```

结果不同，说明 `RS ≠ SR`。有些形状下，`AB` 能算，`BA` 甚至没有定义。矩阵乘法满足结合律，却一般不满足交换律。以上是精确数学关系；浮点运算中的舍入与结合次序留到数值格式章节讨论。

## 6. 维度、秩与信息损失

### 6.1 多一个坐标，不一定多一个独立方向

若两个向量 `v₁ = [1, 2]ᵀ`、`v₂ = [2, 4]ᵀ`，则 `v₂ = 2v₁`。无论怎样组合它们，结果都在同一条直线上。两个向量并没有提供两个独立方向。

一组向量的所有线性组合构成它们的张成空间。若存在一组不全为零的系数，使组合结果为零，这组向量就线性相关；否则就线性无关。在上例中，`2v₁ − v₂ = 0`，所以它们线性相关。概念定义可参阅[线性无关](https://textbooks.math.gatech.edu/ila/linear-independence.html)。

矩阵的秩是它的列向量张成空间的维数，也就是所有可能输出构成的空间有多少个独立方向。对于 `m × n` 矩阵，秩至多为 `min(m, n)`。

开篇矩阵 `A` 有两列，且线性无关：第二列第二个分量是 1，第一列第二个分量是 0，二者不可能互为倍数。因此 `A` 的秩是 2。

虽然 `Ax` 有三个坐标，它仍只会落在三维空间中的一个过原点平面上。事实上，本例总有 `y₃ = 2y₁ − 5y₂`。升到三个输出坐标没有凭空创造第三个独立变化方向。

### 6.2 哪些输入差异会消失

投影矩阵 `P` 把 `(a, b)` 变成 `(a, 0)`。输入 `[1, 2]ᵀ` 和 `[1, 9]ᵀ` 得到相同输出，仅靠输出无法区分它们。

所有满足 `Av = 0` 的输入向量构成 `A` 的零空间。若存在非零 `v` 满足这个条件，那么 `A(x + v) = Ax`：沿 `v` 方向改变输入，输出不变。

这里“信息损失”具体指不同输入映射到同一输出，不是信息论中熵的计算。若零空间只有零向量，映射就不会把不同输入合并；若输入是整个 `ℝⁿ`，输出维数小于 `n` 的线性映射则必然会合并某些输入。

对于方阵，满秩等价于存在逆矩阵，逆变换能恢复输入。矩形矩阵则需区分情况：开篇的 `A` 不是方阵，没有通常意义的双侧逆矩阵，但仍能从有效输出恢复输入：`x₂ = y₂`，`x₁ = y₁ − 2y₂`。

这些结论讨论精确数学中的可区分性，不保证实际低精度计算中的稳定恢复。

### 6.3 为什么把纯线性层叠起来还不够

连续两个纯线性层可以写成 `B(Ax) = (BA)x`。中间没有其他运算时，叠加之后仍然是一个线性变换。

即使每层都加固定偏置，`B(Ax + b₁) + b₂ = BAx + Bb₁ + b₂`，结果也仍是一个仿射变换。增加这种层数不会产生非线性表达能力。

这解释了模型为什么还需要激活函数等非线性运算。具体 FFN 结构放在模型结构卷讨论；从本篇先记住：改变表示维度、增加参数和引入非线性，是不同的事情。

## 7. 回到模型：线性层与 Attention 的形状

### 7.1 从列向量改为按行放 token

前面用 `y = Ax`，一个输入是一列。工程公式常把多个 token 的表示按行排列：

```text
X = ⎡ 1   2 ⎤    第一行是 xᵀ
    ⎣ 3  −1 ⎦    第二行是 zᵀ

Aᵀ = ⎡ 1   0   2 ⎤
     ⎣ 2   1  −1 ⎦

Y = XAᵀ = ⎡ 5   2   0 ⎤
          ⎣ 1  −1   7 ⎦
```

现在每行都是一个输出向量。对应关系来自 `(Ax)ᵀ = xᵀAᵀ`：转置一个乘积，要把各因子转置并倒序。

令 `N` 是这里处理的 token 数，`d_in` 是输入特征数，`d_out` 是输出特征数，两种常见权重约定为：

| 权重约定 | 权重形状 | 输入与输出 |
|---|---|---|
| 按输入到输出记为 `W` | `d_in × d_out` | `Y = XW` |
| 按每个输出的权重记为 `A` | `d_out × d_in` | `Y = XAᵀ` |

两种写法中，`X` 都是 `N × d_in`，`Y` 都是 `N × d_out`。因此看到 `XW` 或 `XWᵀ` 时，应先检查作者怎样定义权重形状。

[PyTorch 2.14 的 Linear 文档](https://docs.pytorch.org/docs/2.14/generated/torch.nn.Linear.html)采用后一类约定：weight 形状为 `(out_features, in_features)`，计算对应输入乘 weight 的转置，再加偏置。实际代码还允许更多前导维，本篇只展示二维输入。

### 7.2 偏置为什么使它成为仿射变换

在线性层里加入固定偏置 `b` 后，每个 token 的输出为 `y = Ax + b`。若 `b` 非零，零输入的输出也是 `b`，已经不满足线性变换要求。

这种“线性变换加平移”叫仿射变换。工程接口常把它统称为 Linear 层，阅读时要区分接口名称和数学定义。

按行计算时，`Y = XAᵀ + b` 表示每一行都加同一个长度为 `d_out` 的偏置。例如 `b = [1, −1, 2]`，上例得到：

```text
Y = ⎡ 6   1   2 ⎤
    ⎣ 2  −2   9 ⎦
```

这里已经说明加法含义；具体的广播规则留到张量基础篇。

### 7.3 Attention 里为什么出现 QKᵀ

先只看单个序列、单个注意力头，省略偏置、位置编码等细节。设 `X` 有 `N` 行，每行是一个 token 的 `d_model` 维表示。用三个权重得到：

```text
X：    N × d_model
W_Q：  d_model × d_k      Q = XW_Q：N × d_k
W_K：  d_model × d_k      K = XW_K：N × d_k
W_V：  d_model × d_v      V = XW_V：N × d_v
```

这里常称“Q/K/V 投影”，但它们通常是学习得到的线性映射，不必是前文那种正交投影。

`Q` 的每行是一个 query 向量，`K` 的每行是一个 key 向量。若要让每个 query 与每个 key 做点积，就要把 key 的行变成列：

```text
QKᵀ：(N × d_k) @ (d_k × N) → N × N
```

结果第 `i` 行、第 `j` 列是第 `i` 个 query 与第 `j` 个 key 的点积。这个 `N × N` 矩阵表示两两分数，还不是注意力概率。

在缩放点积注意力中，分数还需除以 `√d_k`，按任务应用 mask，再逐行经过 softmax 得到权重 `H`。本篇只需理解后续形状：`HV` 是 `(N × N) @ (N × d_v) → N × d_v`，每个输出是 value 向量的加权组合。[Transformer 原论文第 3.2 节](https://arxiv.org/abs/1706.03762v7)介绍了这一计算。

例如 `N = 3`、`d_k = 2`、`d_v = 4`，那么 `QKᵀ` 是 `3 × 3`，最终该头的输出是 `3 × 4`。序列轴负责区分 token，特征轴负责表示每个 token；不能因为两者都是数字就混用。

这里给出数学形状，不表示实现一定会完整保存 `N × N` 中间矩阵。多头、KV Cache、softmax 原理和高效 Attention 分别在后文展开。

## 8. 最小验证与自测

### 8.1 用纯 Python 验证手算

下面只使用 Python 标准库。`matmul` 面向非空、规则的二维列表，用朴素循环展示定义；它不是性能实现，也不处理广播。

```python
from math import sqrt


def matmul(left, right):
    assert left and right and left[0] and right[0]
    assert all(len(row) == len(left[0]) for row in left)
    assert all(len(row) == len(right[0]) for row in right)
    assert len(left[0]) == len(right)
    return [
        [sum(a * b for a, b in zip(row, col))
         for col in zip(*right)]
        for row in left
    ]


A = [[1, 2], [0, 1], [2, -1]]
x = [[1], [2]]
C = [[1, 3], [2, -1]]
X = [[1, 2], [3, -1]]
AT = [list(col) for col in zip(*A)]

assert matmul(A, x) == [[5], [2], [0]]
assert matmul(A, C) == [[5, 1], [2, -1], [0, 7]]
assert matmul(X, AT) == [[5, 2, 0], [1, -1, 7]]

S = [[2, 0], [0, 1]]
R = [[0, -1], [1, 0]]
assert matmul(R, matmul(S, x)) == [[-2], [2]]
assert matmul(S, matmul(R, x)) == [[-4], [1]]

u, v = [1, 2], [3, -1]
dot = sum(a * b for a, b in zip(u, v))
assert dot == 1
assert sum(a * (10 * b) for a, b in zip(u, v)) == 10
assert abs(sqrt(sum(a * a for a in u)) - sqrt(5)) < 1e-12
print("手算、行列约定、变换顺序与点积验证通过")
```

这些断言把正文里的几种解释放到一起核对。要进一步检查自己的理解，可以换一个输入，先手算，再运行代码。

### 8.2 先独立回答，再看参考答案

1. `U` 形状是 `4 × 3`，`V` 形状是 `3 × 2`。`UV` 的形状是什么？`VU` 能计算吗？
2. 用开篇矩阵 `A` 计算 `A[2, −1]ᵀ`。你能分别按行点积、按列组合解释吗？
3. `f(x) = 3x + 1` 是线性变换吗？`g(x) = x²` 呢？
4. 两个输入向量有三个输出分量，是否一定可以恢复输入？
5. 已知 `Q`、`K` 都是 `5 × 2`，`V` 是 `5 × 3`。两两点积矩阵和加权输出分别是什么形状？
6. 先用 `A` 变换列向量，再用 `B` 变换，合并矩阵是 `AB` 还是 `BA`？

参考答案：

1. `UV` 是 `4 × 2`。`VU` 的内维是 2 和 4，不相等，不能计算。
2. 结果是 `[0, −1, 5]ᵀ`。按列看，是 `2a₁ − a₂`；按行看，是三行权重分别与 `[2, −1]ᵀ` 做点积。
3. 都不是。`f(0) = 1`，是仿射变换；`g(1 + 1) = 4`，而 `g(1) + g(1) = 2`，不满足可加性。
4. 不一定。能否恢复由映射是否合并不同输入决定，不能只看输出分量数；开篇矩阵可以恢复，但零矩阵显然不能。
5. `QKᵀ` 是 `5 × 5`；若由它得到同形状的注意力权重，乘 `V` 后输出是 `5 × 3`。
6. `BA`，因为实际计算是 `B(Ax)`。
