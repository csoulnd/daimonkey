# 报告厅框架示例

这份报告用于验证「报告厅」模块的完整渲染链路：清单登记 → 内容渲染 → 页面产出。
熟悉之后可以删除 `reports/hello-report/` 目录并移除清单中的对应条目。

## 支持的内容形态

报告内容可以是网页展示或 PPT 展示，按文件扩展名自动分发：

| 内容文件 | 展示方式 | 适用场景 |
|---|---|---|
| `report.md` | 站内渲染（Markdown → 页面） | 笔记型、结构化的文字报告 |
| `index.html` / `report.html` | 原样网页：详情页内嵌 + 新窗口打开 | 带自定义样式/脚本的完整网页报告（如工具生成的 HTML 汇报） |
| `deck.pptx` | 演示文稿原件下载（网页化预览为后续规划） | 正式的 PPT 汇报 |

## 素材从哪来

报告的**原材料**来自知识库（`/knowledge`，本地快照在 `data/knowledge-repo/`）、
站内榜单与新闻数据、以及外部资料。撰写时把这些素材消化为报告内容，并在清单的
`materials:` 字段登记引用，详情页会展示为"参考材料"。
