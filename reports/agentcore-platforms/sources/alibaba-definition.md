# 阿里云 AgentCore · 平台定义

## 官方定义

阿里云 AgentCore 是**智能体构建和治理平台**：企业可以在其中创建、接入和统一管理智能体。

官方以「**统一构建、统一纳管、统一治理**」组织平台能力；核心理念为 **Agent = Model + Harness**。

平台围绕 **Workspace、Agent、Team** 与资产体系组织：模型连接、Agent、Skill、MCP 和凭证均在 Workspace 中管理。

生命周期四阶段：**构建与准入 → 组织与交付 → 评测与进化 → 沉淀与复用**。

## 面向谁

面向**企业**：由企业 AI 中台或类似定位的技术团队，统一治理多源智能体——

- 员工使用的 Coding 与办公智能体；
- 部门自建的 Agent；
- 外采的 SaaS 服务。

## 概念与边界

- **平台、执行引擎与模型入口是三件事**：AgentCore 是平台；**QwenPaw／Qoder** 是托管 Harness 的执行引擎；模型连接提供模型访问配置。
- 平台的核心对象是 **Workspace、Agent、Team** 与资产体系，而不是单个 Agent 的运行。

## 接入路径

| 模式 | 用户提供 | 平台负责 |
|---|---|---|
| 托管 Harness | 引擎选择、角色、模型、资产绑定 | Harness 运行与实例／会话管理 |
| 高代码 Agent | 应用代码、容器镜像、服务契约 | 镜像托管运行、资源与平台接入 |
| 已有 Agent 纳管 | 已有部署与接入配置 | 统一管理与协作接入 |
