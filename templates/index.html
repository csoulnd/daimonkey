评分说明

三方向频道：智能体、模型、硬件三个方向各自提供新闻流、榜单与每周总结；方向顺序、关联榜单与新闻范围全部由配置定义，可按讨论演进调整。

智能体核心榜：只收面向用户可用、具备自主执行或多步编排的产品。按 GitHub Stars 优先排序，无仓库产品按 npm 月下载与商店排名列后，所有数字可在产品页回查原始响应。

生态项目榜：协议（MCP）、库/框架（LangChain）、编排工具（n8n）等按生态维度单独成榜，与核心产品榜平行展示，使用同一套公开采纳指标。

模型榜：以 Artificial Analysis Intelligence Index 从高到低排序，自动收录当前主流模型（同系列取最高分版本，前 40）；编码指数与 Agent 指数作为细分能力参考列。

硬件榜：按 MLPerf Inference 官方 Closed 分区的单卡离线吞吐排序，辅以厂商公开的算力、显存、互联与功耗规格；厂商未披露的数值以“—”表示。
