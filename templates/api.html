公开 JSON API 静态文件 · 契约冻结

Phase 1 的 API 是构建期生成的静态 JSON 文件（本站页面与外部引用同一份）； 未来若替换为 FastAPI 只读服务，路径与结构不变，前端与调用方零改动。

端点说明
GET /api/v1/boards.json榜单目录（产品数、观察区数、快照日期）
GET /api/v1/rankings/{board}.json某榜最新快照。board ∈ harness_core / harness_eco / model / domestic / domestic_app；unified 为已并入核心榜的只读兼容别名。指标带 tier / source / collected_at / raw_payload_id；meta 含配置与实际生效权重
GET /api/v1/rankings/{board}/history.json近 90 天榜单历史序列
GET /api/v1/hardware/ladder.json硬件天梯（FP16 算力/低精度/显存/带宽/官方文档，规格口径）
GET /api/v1/products/{slug}.json产品详情：信息、接入适配度、指标时序（含每点的溯源 id）
GET /api/v1/raw/{payload_id}.json原始 HTTP 响应归档（响应体按 LRU 清理后 raw_body 为 null，元数据与 sha256 永在）
GET /api/v1/insights.json领域进展列表（预留）
GET /api/v1/meta.json全局元信息：口径版本、最后采集时间、数据源健康、LRU 配置、计数

模型榜说明：items 按 AA Intelligence Index 总评分排序，成员来自 AA 免费 API 自动同步的 Top 40（去重同系列变体）；metrics 含 aa_intelligence / aa_coding / aa_agentic，逐项带 source 与 raw_payload_id。SuperCLUE 已停用，历史数据仅存档。

动态端点（仅本地服务模式）

端点说明
POST /api/v1/update触发一次完整更新（采集→评分→LRU→导出→建站）。需通过 X-Update-Password 请求头验证更新密码
GET /api/v1/update/status更新状态：never / running / success / partial / failed
GET /api/v1/knowledge/search只读全文搜索。参数 q / group / path / offset / limit；默认每页 40 条，最多 100 条。返回 total 与 results（标题、路径、链接与匹配片段），不传输完整正文

示例

curl http://127.0.0.1:8080/api/v1/rankings/harness_core.json | head -40
curl http://127.0.0.1:8080/api/v1/meta.json
